Keep the assistant from reporting a usable CAD tool as unavailable. The Claude CLI bridge now traces the refusals the CLI makes inside a run, retries a step in which the model dropped a tool the browser does offer, reads decorated tool names and JSON-string arguments instead of refusing them, caps a run's turns, and writes one diagnostic line per step to the service log (counts, error codes and tool names only). The abutment dossier is refused through `chay_template` and sent to `tao_ho_so_mo`, so a dossier always goes through the duplicate-name check, the detail-mode report and the view refresh.
